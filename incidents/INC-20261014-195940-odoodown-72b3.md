## Summary
On 2026-10-14, the Odoo application became unavailable when the `sentra-odoo-1` container exited. The service was restored by restarting the container once the database was confirmed to be healthy.

## Root cause
The Odoo application crashed due to a `psycopg2.OperationalError` caused by a database connection failure. Logs indicate the PostgreSQL database received a "fast shutdown request" at 19:54:03, which terminated the connection while Odoo was running.

## Resolution
The `sentra-odoo-1` container was manually restarted. Upon restart, the application successfully re-established a connection to the database, which was already back in a healthy state.

## Prevention
- Investigate the source of the "fast shutdown request" sent to the PostgreSQL database to ensure no unauthorized or misconfigured processes triggered it.
- Implement automated health checks that automatically restart the Odoo container if a connection failure to the database is detected.
- Review database maintenance schedules or automated task configurations to identify why a shutdown request occurred during business hours.
